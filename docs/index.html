Install

One command, two entrypoints.

Homebrew installs both syncpick and the shorter sp command.

$ brew install Cyberlane/tap/syncpick

The workflow

From remote list to local copy, without losing context.

Configure once. Pick what you need. Review exactly what will happen before rsync starts.

  1. 01

    Connect

    Save a friendly profile for an SSH host and one or more remote roots.

    syncpick --init
  2. 02

    Pick

    Browse immediate subfolders, move with Vim keys, and queue one or many with Tab.

    sp ~/Downloads
  3. 03

    Review & sync

    Confirm the selected paths, destination, and transfer mode. Press y once to proceed.

    sp --dry-run

Safe by default

A small tool with an intentionally narrow blast radius.

syncpick shows the selected sources and resolved destination before a real transfer. Destructive behavior stays opt-in.
